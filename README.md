# Handwritten Digit Recognition

## Overview
This project implements a handwritten digit recognition system using machine learning algorithms and the MNIST dataset. It classifies handwritten digits from 0 to 9 using Support Vector Machine (SVM), K-Nearest Neighbors (KNN), and Random Forest classifiers.

## Features
- Uses the MNIST dataset of handwritten digits.
- Implements SVM, KNN, and Random Forest classification algorithms.
- Evaluates model performance using accuracy score and confusion matrix.
- Visualizes handwritten digits and results using Matplotlib.

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- MNIST Dataset

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/souravisaha/handwritten-digit-recognition.git
   ```

2. Navigate to the project directory:

   ```bash
   cd handwritten-digit-recognition
   ```

3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

## How to Run

Open `handwritten_digit_recognition.ipynb` in Google Colab or Jupyter Notebook and run the cells in order.

The notebook loads the MNIST dataset, trains the classification models, and evaluates their performance.

## Evaluation Metrics
- Accuracy Score
- Confusion Matrix

## Dataset
The project uses the MNIST dataset, a collection of handwritten digit images labeled from 0 to 9, available through TensorFlow/Keras.
